## 📌 What is this repo?

This is **not a project repo.**

It's my personal notebook for Machine Learning — where I document concepts, intuitions, and theory as I work through them. No boilerplate, no tutorials copied — just my own understanding, written in my own words.

> Think of it as my ML brain dump, structured and version-controlled.

---

## 📂 What's inside

- Core ML algorithm breakdowns (how they work, when to use them, why they work)
- Mathematical intuitions explained simply
- Key terms, formulas, and decision rules
- Interview-ready concept summaries
- Topic-by-topic notes as I progress through the roadmap

Most people learn ML and never write down *why* something works — only *that* it works.

This repo fixes that. Every note here is an attempt to actually understand the concept well enough to explain it from scratch — which is exactly what interviews and real engineering demand.
